JPAを用いた正規化データベースとスコアリングアルゴリズムチャンピオンの基本情報と、ロール・レーン・ビジュアル等のタグ情報を別テーブルに分離し、多対多（Many-to-Many）のリレーションシップを構築しました。これにより、適性診断機能において「特定の属性を持つチャンピオンにポイントを加算する」という複雑なスコアリング計算を、柔軟かつ正確に行うことを可能にしています。DTO（Data Transfer Object）層を設けることで、フロントエンドには整形された軽量なJSONのみを返却しています。5. SPAライクなシームレスUIとリッチアニメーションユーザー体験を損なうページロードを無くすため、単一の index.html 上でJavaScriptによる非同期データ取得とクラス制御を行い、SPA風のサクサク動く画面遷移を実現しました。また、クイズ中のキルストリーク演出では、ブラウザのレンダリング（リフロー）をJavaScriptで明示的に制御し、CSSの @keyframes を用いたアニメーションを実装。ゲーム本来の爽快感をブラウザ上で表現しています。6.
